# agents.md

## Coding practices

* Prefer clean, readable, maintainable code over quick hacks.
* Keep functions and classes focused on a single responsibility.
* Add detailed comments that explains function as well as how it works in the system as a whole. 

## Architecture

* Do not put too much logic into one file.
* Do not create god objects or giant classes that own too many responsibilities.
* Split the system into multiple smaller files and modules with clear boundaries.
* Organize code so that world logic, rendering, simulation, agents, utilities, and configuration are separated.

## Maintainability

* Create many smaller, understandable files instead of one large file.
* Keep files cohesive and focused.
